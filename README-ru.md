# Hunter Focus Arc

Перемещаемый индикатор фокуса охотника для LOTRO. Доступны пять форм — дуга, лук, колчан следопыта, печать трёх путей и веер стрел — и четыре независимых стиля: лунное серебро, солнечная бронза, золото Лориэна и сумрачный обсидиан. Каждая из 20 комбинаций показывает девять делений группами по три и текущее значение цифрой.

## Загрузка и настройки

Папка `HunterFocusArc` находится в каталоге `Plugins`. В игре откройте **Менеджер плагинов** и загрузите **Hunter Focus Arc**. Плагин работает только для класса «Охотник».

На вкладке **Настройки** выберите форму и стиль кнопками. Предпросмотр показывает выбранное сочетание при 6 единицах фокуса. Выбор применяется сразу и сохраняется отдельно для каждого персонажа. Старый выбор темы `Moon Hunter` или `Lunar Bow` автоматически переносится в новую систему без изменения внешнего вида.

## Управление

Нажмите `Ctrl+\`, чтобы включить штатный режим размещения интерфейса LOTRO. В этом режиме индикатор можно перетаскивать за любую часть его области. Повторно нажмите `Ctrl+\`, чтобы выйти из режима. Положение сохраняется автоматически.

| Команда | Действие |
| --- | --- |
| `/hfocus form arc` | Выбрать форму: `arc`, `bow`, `quiver`, `sigil`, `fan` |
| `/hfocus form next` | Переключить на следующую форму |
| `/hfocus style moon` | Выбрать стиль: `moon`, `sun`, `forest`, `shadow` |
| `/hfocus style next` | Переключить на следующий стиль |
| `/hfocus size 115` | Изменить размер в процентах (80–200) |
| `/hfocus show` / `/hfocus hide` | Показать / скрыть индикатор |
| `/hfocus reset` | Вернуть положение и размер по умолчанию |

Старые команды `/hfocus theme moon`, `/hfocus theme bow` и `/hfocus theme next` тоже работают. Плагин отслеживает переключение режима размещения, но LOTRO не сообщает ему, включён ли режим в момент загрузки. Если плагин загружен уже при включённом режиме размещения, выйдите из него и перезагрузите плагин.

Штатный индикатор LOTRO остаётся на месте. При необходимости переместите или скройте его штатными настройками интерфейса игры.

## Производительность

Все 10 состояний фокуса для каждого сочетания заранее отрисованы в прозрачные TGA 140×100 пикселей. В игре плагин получает событие `FocusChanged`, проверяет, изменилось ли целое значение, и только после этого меняет одну текстуру. Постоянного обновления каждый кадр нет. Настройки сохраняются при изменении выбора, положения или размера, а не при каждом событии фокуса.

Графика создана специально для плагина; это стилизация, а не извлечённая из клиента текстура. Скрипт `generate_variants.py` воспроизводит новые варианты. Две исходные лунные темы сохраняют прежние изображения.
