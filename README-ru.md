# Hunter Focus Arc

Дугообразный индикатор Focus охотника для LOTRO с двумя темами. В теме «Лунный охотник» фокус заполняет серебряную дугу и девять лунных камней. В теме «Лунный лук» дуга становится луком с тетивой и девятью светящимися наконечниками; тетива натягивается по мере накопления фокуса. Деления в обеих темах расположены группами по три, а текущее значение показано цифрой на вершине дуги. Настройки сохраняются отдельно для каждого персонажа.

## Загрузка

Папка `HunterFocusArc` уже находится в каталоге `Plugins`. В игре откройте **Менеджер плагинов** и загрузите **Hunter Focus Arc**. Плагин работает только для класса «Охотник». На вкладке **Настройки** этого плагина можно выбрать тему по её кнопке; рядом показан её вид при 6 единицах фокуса. Выбор применяется сразу.

## Управление

Нажмите `Ctrl+\`, чтобы включить штатный режим размещения интерфейса LOTRO. В этом режиме дугу можно перетаскивать за любую часть её области. Повторно нажмите `Ctrl+\`, чтобы выйти из режима: дуга перестанет перехватывать мышь. Положение сохраняется автоматически.

| Команда | Действие |
| --- | --- |
| `/hfocus size 115` | Изменить размер в процентах (80–200) |
| `/hfocus theme moon` | Включить тему «Лунный охотник» |
| `/hfocus theme bow` | Включить тему «Лунный лук» |
| `/hfocus theme next` | Переключить на другую тему |
| `/hfocus theme` | Показать текущую тему и команды выбора |
| `/hfocus show` | Показать индикатор |
| `/hfocus hide` | Скрыть индикатор |
| `/hfocus reset` | Вернуть положение и размер по умолчанию |

Плагин отслеживает переключение режима размещения, но LOTRO не сообщает ему, включён ли режим в момент загрузки. Если плагин загружен уже при включённом режиме размещения, выйдите из него и перезагрузите плагин.

Штатный индикатор LOTRO остаётся на своём месте. Если он больше не нужен, переместите или скройте его штатными настройками интерфейса игры.

Графика обеих тем создана специально для этого плагина; это стилизация, а не извлечённая из клиента текстура. `preview.png` показывает «Лунного охотника», `preview-bow.png` — «Лунный лук».
