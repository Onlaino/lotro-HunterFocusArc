# Hunter Focus Arc

Дугообразный индикатор Focus охотника для LOTRO в оформлении «Лунный охотник». Текущее значение показано цифрой в серебряном медальоне на вершине дуги. Девять лунных камней расположены тремя группами по три. Бирюзовая линия заполняется вместе с Focus, а серебряные метки отделяют группы. Индикатор обновляется при изменении Focus и сохраняет настройки отдельно для каждого персонажа.

## Загрузка

Папка `HunterFocusArc` уже находится в каталоге `Plugins`. В игре откройте **Менеджер плагинов** и загрузите **Hunter Focus Arc**. Плагин работает только для класса «Охотник».

## Управление

Нажмите `Ctrl+\`, чтобы включить штатный режим размещения интерфейса LOTRO. В этом режиме дугу можно перетаскивать за любую часть её области. Повторно нажмите `Ctrl+\`, чтобы выйти из режима: дуга перестанет перехватывать мышь. Положение сохраняется автоматически.

| Команда | Действие |
| --- | --- |
| `/hfocus size 115` | Изменить размер в процентах (80–200) |
| `/hfocus show` | Показать индикатор |
| `/hfocus hide` | Скрыть индикатор |
| `/hfocus reset` | Вернуть положение и размер по умолчанию |

Плагин отслеживает переключение режима размещения, но LOTRO не сообщает ему, включён ли режим в момент загрузки. Если плагин загружен уже при включённом режиме размещения, выйдите из него и перезагрузите плагин.

Штатный индикатор LOTRO остаётся на своём месте. Если он больше не нужен, переместите или скройте его штатными настройками интерфейса игры.

Графика дуги создана специально для этого плагина; это стилизация, а не извлечённая из клиента текстура.
