# Hunter Focus Arc

Перемещаемый индикатор фокуса охотника для LOTRO. Доступны семь форм — дуга, лук, колчан следопыта, печать трёх путей, веер стрел, компактная прямая линия с круглыми делениями и «Ветка Лориэна» с девятью светящимися листьями. Для каждой формы доступны четыре независимых стиля: лунное серебро, солнечная бронза, золото Лориэна и сумрачный обсидиан. Каждая из 28 комбинаций показывает девять делений группами по три и текущее значение цифрой.

## Загрузка и настройки

Папка `HunterFocusArc` находится в каталоге `Plugins`. В игре откройте **Менеджер плагинов** и загрузите **Hunter Focus Arc**. Плагин работает только для класса «Охотник».

На вкладке **Настройки** есть разделы **Appearance** (форма и стиль) и **Size / rotation** (размер и поворот). В разделе Appearance крупный предпросмотр показывает выбранное сочетание при 6 единицах фокуса; кнопки **Prev** и **Next** переключают все семь форм и четыре стиля. Выбор и трансформация применяются сразу и сохраняются отдельно для каждого персонажа. Старый выбор темы `Moon Hunter` или `Lunar Bow` автоматически переносится в новую систему. Лунная дуга теперь использует переработанный рисунок; лунный лук сохраняет прежний.

## Управление

Нажмите `Ctrl+\`, чтобы включить штатный режим размещения интерфейса LOTRO. В этом режиме индикатор можно перетаскивать левой кнопкой, поворачивать движением мыши с зажатой правой кнопкой и менять размер колесом мыши с шагом 5%. Повторно нажмите `Ctrl+\`, чтобы выйти из режима. Положение, размер и угол сохраняются автоматически. Точное значение можно задать в настройках плагина или командой.

| Команда | Действие |
| --- | --- |
| `/hfocus form arc` | Выбрать форму: `arc`, `bow`, `quiver`, `sigil`, `fan`, `line`, `branch` |
| `/hfocus form next` | Переключить на следующую форму |
| `/hfocus style moon` | Выбрать стиль: `moon`, `sun`, `forest`, `shadow` |
| `/hfocus style next` | Переключить на следующий стиль |
| `/hfocus size 115` | Изменить размер в процентах (50–300) |
| `/hfocus rotate 37` | Установить угол в градусах; число приводится к диапазону 0–359 |
| `/hfocus rotate reset` | Вернуть угол 0° |
| `/hfocus show` / `/hfocus hide` | Показать / скрыть индикатор |
| `/hfocus reset` | Вернуть положение, размер и угол по умолчанию |

Старые команды `/hfocus theme moon`, `/hfocus theme bow` и `/hfocus theme next` тоже работают. Плагин отслеживает переключение режима размещения, но LOTRO не сообщает ему, включён ли режим в момент загрузки. Если плагин загружен уже при включённом режиме размещения, выйдите из него и перезагрузите плагин.

Штатный индикатор LOTRO остаётся на месте. При необходимости переместите или скройте его штатными настройками интерфейса игры.

## Производительность

Все 10 состояний фокуса для каждого сочетания заранее отрисованы в прозрачные TGA 140×100 пикселей. В игре плагин получает событие `FocusChanged`, проверяет, изменилось ли целое значение, и только после этого меняет одну текстуру. Постоянного обновления каждый кадр нет. Настройки сохраняются при изменении выбора, положения, размера или угла, а не при каждом событии фокуса. Во время поворота мышью запись происходит только при отпускании кнопки.

Графика создана специально для плагина; это стилизация, а не извлечённая из клиента текстура. Скрипт `generate_variants.py` воспроизводит новые варианты. Дуга, ветвь и прямая шкала обновлены во всех четырёх стилях: крупные отметки и разделение по тройкам лучше видны в игровом размере. Лунный лук сохраняет прежние изображения. Поворот и масштабирование зависят от отрисовки интерфейса LOTRO; после обновления стоит проверить их в игре при вашем разрешении экрана.
